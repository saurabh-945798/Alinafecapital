ALINAFE CAPITAL - FRONTEND BANK LOGO HOTFIX
Date: 15 September 2026

Purpose
- Fixes the National Bank of Malawi logo in the Bank Payment repayment card.
- Removes the large unused white space contained in the original image file.
- Keeps the official logo proportions intact and allows it to display at a size comparable to the Card and Airtel Money options.

Installation
1. Back up the current frontend folder.
2. Replace the existing frontend folder with the frontend folder in this ZIP, or copy its contents over the current frontend folder.
3. Run npm ci inside frontend if dependencies are not installed.
4. Restart the frontend development/production process.

No backend or admin changes are included in this hotfix.
